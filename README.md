# ByteBites Tinker Activity

This repository contains a simple backend model for the ByteBites application. It defines core classes for managing customers, food items, menus, and orders. The goal of the tinker activity is to implement and verify basic functionality such as filtering menu items by category and computing order totals.

---

## Weekly Task Summary

**Core concept:** Learning to leverage AI tools such as GitHub Copilot to assist with system design, code scaffolding, and testing while maintaining control over the architecture and implementation.

**Where students are most likely to struggle:** Identifying nouns and requirements and translating them into classes. Students might also struggle understanding object relationships.

**Where AI was helpful:** When working with the ByteBites Design Agent, a set of guidelines made the output much closer to what was expected. This also saved time by eliminating the need to specify constraints at every prompt.

**Where AI was misleading:** When creating the UML class diagram, Copilot added attributes that were not required per the spec and suggested irrelevant methods.

**How I would guide a student without giving away the answer:** Provide a brief explanation of what a noun is when they need to identify nouns to build the UML diagram. Offer an analogy if they have questions about the types of relationships that can exist between two classes.

## Features

- Add and remove `FoodItem` instances to a `Menu`
- Filter menu items by category
- Sort menu items by price (ascending) or popularity rating (descending)
- Create an `Order` and compute its total cost using `Decimal` for precision
- Maintain a customer's purchase history across multiple orders

---

## Classes

- **FoodItem** — a single menu entry with name, price, category, and popularity rating
- **Menu** — manages the full collection of food items; supports filtering and sorting
- **Order** — groups selected items into a transaction and computes the total cost
- **Customer** — represents a registered user and tracks their purchase history
